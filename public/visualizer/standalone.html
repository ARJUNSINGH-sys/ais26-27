01 / ARCHITECTURE OVERVIEW 8 min read

The Transformer Architecture: Discarding Recurrence

Sequential computation eliminated in favor of global parallel attention

Before 2017, the undisputed state-of-the-art in sequence transduction models was dominated by recurrent neural networks (RNNs, LSTMs, GRUs). Recurrent models process input sequences along the sequential temporal axis:

ht = f(ht-1, xt)

This sequential processing precludes parallelization within training examples, creating severe bottlenecks on GPU hardware. Furthermore, signals between distant tokens must traverse O(n) recurrent steps, exacerbating vanishing gradients across long contexts.

Vaswani et al. introduced the Transformer: a model architecture relying solely on an attention mechanism to model dependencies between inputs and outputs. The maximum path length between any two tokens drops to O(1), enabling massive parallelization during training.

CANONICAL COMPLEXITY COMPARISON
Self-Attention: O(1) Sequential Operations vs RNN: O(n)
Path length between any two tokens: Self-Attention = O(1) | Recurrent = O(n) | Convolutional = O(log_k n)

02 / TOKENIZATION & SUBWORDS 7 min read

Tokenization & Byte-Pair Encoding (BPE)

Bridging raw characters and vector representations with |V| = 37,000 subwords

Before any vector math or attention can occur, discrete natural language text must be converted into a discrete sequence of integer token IDs. In Section 5.1 of Attention Is All You Need, the authors state:

"On the English-to-German task, we trained using byte-pair encoding (BPE), which has a shared source-target vocabulary of about 37,000 tokens. For English-French, we used a vocabulary of 32,000 word-piece units."

Why subwords instead of full words or raw characters?

  • Word-Level Tokenization: Fails on out-of-vocabulary (OOV) words, misspelling, and novel compound words (e.g. German compound nouns). Vocabularies explode to millions of words, inflating embedding tables.
  • Character-Level Tokenization: Eliminates OOV, but sequence lengths explode $5\times$ to $10\times$. Since self-attention memory and computation scale quadratically $O(N^2)$, 1,000 characters would require a $1,000 \times 1,000$ attention matrix ($100\times$ more memory than 100 subwords).
  • Byte-Pair Encoding (BPE): The perfect middle ground. Common words remain single tokens (`"the"`, `"attention"`), while rare or inflected words are split into meaningful morphemic pieces (`"trans"`, `"##form"`, `"##er"`).
BPE ALGORITHM CONTRACT
Raw Text ⟶ Character Slicing ⟶ Iterative Frequent Pair Merging ⟶ Token IDs ∈ [0, 37000) ⟶ Lookup in E ∈ ℝ^{37000 × 512}
Sequence length shrinks by ~75% vs character-level while maintaining 0% Out-Of-Vocabulary rate

03 / EMBEDDINGS & SCALING 5 min read

Input Embeddings & The Vital Scaling by √dmodel

Preserving semantic dominance over additive positional encodings

Discrete words/tokens are projected into continuous vector space ℝdmodel via a learned embedding matrix. The paper uses a vocabulary of $|V| \approx 37,000$ BPE tokens and dimension $d_{model} = 512$.

Crucially, in Section 3.4, the authors state: "In the embedding layers, we multiply those weights by $\sqrt{d_{model}}$." Why? Because when embedding weights are initialized with standard Gaussian variance (on the order of $1 / \sqrt{d_{model}}$), their vector magnitudes are approximately 1.0. Adding positional encodings (which have values strictly in $[-1, 1]$ and an average norm of $\approx \sqrt{d_{model} / 2}$) would otherwise drown out the semantic token signal with positional noise. Multiplying by $\sqrt{512} \approx 22.63$ ensures semantic features dominate early layer activations.

EMBEDDING SCALING EQUATION
Escaled = Embedding(x) · √dmodel = Embedding(x) · √512 ≈ Embedding(x) · 22.627
Input tokens: [Batch, Seq_Len] → Embedding Matrix: [37000, 512] → Scaled Output: [Batch, Seq_Len, 512]

04 / POSITIONAL ENCODINGS 8 min read

Sinusoidal Positional Encoding & Harmonic Frequencies

Injecting sequence order into permutation-invariant self-attention

Because self-attention performs operations across all token pairs simultaneously, it is completely permutation-invariant: if you shuffle the words in an input sentence, self-attention computes the exact same attention outputs, merely shuffled in order!

To give the model awareness of token order, positional encodings are added to the input embeddings. Rather than learned embeddings that fail to extrapolate to longer sequences, Vaswani et al. formulated fixed sinusoidal functions across geometric frequencies:

SINUSOIDAL POSITIONAL FORMULATION
PE(pos, 2i) = sin(pos / 100002i / dmodel),   PE(pos, 2i+1) = cos(pos / 100002i / dmodel)
Wavelengths form a geometric progression from 2π to 10000·2π (pos ∈ [0, max_len], i ∈ [0, 255])
2D/3D HARMONIC POSITIONAL SPECTRUM (LIVE CONTINUOUS WAVE)
LINEAR SHIFT INVARIANCE
High Frequencies (Left, local syntax) → Low Frequencies (Right, long-range global context)
SAMPLE TOKENS: 20

Why is this mathematically profound? For any fixed offset $k$, $PE_{pos+k}$ can be represented as a direct linear transformation of $PE_{pos}$. By standard trigonometric angle addition:

sin(ω(pos + k)) = sin(ω pos)·cos(ω k) + cos(ω pos)·sin(ω k)

This enables the self-attention mechanism to learn to attend to relative positions via simple linear projection matrices!

05 / SCALED ATTENTION 9 min read

Scaled Dot-Product Attention: The Core Engine

Preventing vanishing gradients caused by softmax saturation

An attention function maps a query and a set of key-value pairs to an output. The queries ($Q$), keys ($K$), and values ($V$) are packed into matrices:

SCALED DOT-PRODUCT ATTENTION FORMULA
Attention(Q, K, V) = softmax( (Q · KT) / √dk ) · V
Q, K ∈ ℝN × d_k, V ∈ ℝN × d_v → Attention Weights A ∈ ℝN × N → Output ∈ ℝN × d_v

06 / MULTI-HEAD ATTENTION 10 min read

Multi-Head Attention: Subspace Specialization

Jointly attending to information from different representation subspaces

Instead of performing a single attention function with 512-dimensional vectors, the authors linearly project queries, keys, and values $h=8$ times with learned projections to dimension $d_k = d_v = d_{model}/h = 64$.

MULTI-HEAD FORMULATION
MultiHead(Q,K,V) = Concat(head1, ..., head8) · WO,   headi = Attention(Q·WiQ, K·WiK, V·WiV)
W_i^Q, W_i^K, W_i^V ∈ ℝ^{512 × 64}, W^O ∈ ℝ^{512 × 512} · Total compute identical to single full attention

08 / RESIDUAL & LAYERNORM 7 min read

Residual Connections & Layer Normalization

Gradient highways preserving backpropagation through deep stacks

Every sub-layer in both encoder and decoder is wrapped in a residual connection followed by layer normalization:

ADD & NORM RESIDUAL EQUATION
Output = LayerNorm( x + Sublayer(x) )
LayerNorm(z) = [ (z - μ) / √(σ² + ε) ] ⊙ γ + β (computed across d_model independently for each token)

The residual connection $x + f(x)$ creates an unbroken identity gradient highway $\partial L / \partial x = \partial L / \partial y \cdot (1 + \partial f / \partial x)$. Even if gradients through the sub-layer vanish, the signal persists undiminished via the $1$ term!

09 / DECODER & CAUSALITY 8 min read

The Autoregressive Decoder & Causal Masking

Enforcing the auto-regressive property during parallel training

During inference, language models generate tokens one by one: token $t$ depends strictly on $w_1, \dots, w_{t-1}$. But training sequentially would ruin GPU throughput.

Causal Masking resolves this: All target tokens are fed into the decoder concurrently, but an upper-triangular mask of $-\infty$ is added to the dot-product logits prior to softmax. Since $e^{-\infty} = 0$, attention to future tokens is mathematically prohibited!

CAUSAL MASK DEFINITION
Mij = 0 if j ≤ i  |  -∞ if j > i  ⟹  softmax( (QKT / √dk) + M )
Ensures exact mathematical equivalence between parallel training and step-by-step inference

10 / CROSS-ATTENTION 8 min read

Cross-Attention: The Encoder-Decoder Bridge

Queries from the Decoder attend over Keys and Values from the Encoder

In the middle sub-layer of every decoder layer, the model performs cross-attention. Here, the Queries come from the previous decoder sub-layer (representing what has been translated so far), while the Keys and Values come from the final output of the 6-layer encoder stack (representing the full source sentence).

CROSS-ATTENTION EQUATION
Q = Decoderprev · WQ,   K = Encoderfinal · WK,   V = Encoderfinal · WV
Attention matrix shape is [N_target × N_source] (bipartite language translation alignment)

11 / OPTIMIZATION 6 min read

Training Regime, Noam Warmup & Regularization

Stabilizing early attention weights with dynamic learning rate scheduling

Training transformers requires delicate optimization. The authors employed the Adam optimizer with $\beta_1 = 0.9, \beta_2 = 0.98, \epsilon = 10^{-9}$ and designed the Noam Learning Rate Schedule:

NOAM LEARNING RATE FORMULA
lrate = dmodel-0.5 · min( step-0.5,   step · warmup_steps-1.5 )
warmup_steps = 4000 · Increases linearly for 4k steps, then decays with inverse square root of step number
